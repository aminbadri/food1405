# وب‌اپ گزارش‌گیری و تحلیل هزینه غذا

وب‌اپ فارسی برای بارگذاری فایل اطلاعات سلف و فایل قیمت‌ها، فیلتر تاریخ شمسی و تولید گزارش Excel راست‌به‌چپ.

## امکانات
- فیلتر بازه تاریخ با تقویم شمسی و انتخاب ماه و سال
- تطبیق نام غذا با فایل قیمت‌ها و انتخاب ستون قیمت
- گزارش تفکیکی تعداد پرس و مبلغ قیمت انتخابی برای دسته‌های کم‌هزینه، متوسط‌هزینه و پرهزینه
- محاسبه میانگین مبلغ هر پرس برای هر دسته و میانگین کل (جمع مبلغ تقسیم بر تعداد پرس)
- خروجی Excel شامل گزارش نهایی و خلاصه مدیریتی

## اجرا و انتشار
فایل `index.html` را در مرورگر باز کنید یا مخزن را به Vercel متصل کنید. کتابخانه‌های XLSX و ExcelJS از CDN بارگذاری می‌شوند؛ بنابراین برای کارکرد کامل، اتصال اینترنت لازم است.

## حریم خصوصی
فایل‌های ورودی کاربران در مرورگر پردازش می‌شوند؛ فایل‌های واقعی داده را در مخزن GitHub بارگذاری نکنید.
